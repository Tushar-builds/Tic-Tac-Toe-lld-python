# Tic-Tac-Toe Game (Python OOP + LLD)

A console-based Tic-Tac-Toe game built using Object-Oriented Programming principles and Low Level Design concepts in Python.

This project was created to strengthen understanding of:

* OOP Design
* Class Responsibilities
* Game Flow Management
* Clean Code Structure
* Low Level Design Fundamentals

---

# 🚀 Features

* Two-player turn-based gameplay
* Dynamic board updates
* Input validation
* Prevention of overwriting moves
* Win detection:

  * Rows
  * Columns
  * Diagonals
* Draw detection
* Clean and modular class-based design

---

# 🛠 Tech Stack

* Python 3

---

# 🧠 Low Level Design Concepts Used

## Classes & Responsibilities

### Player

Handles:

* Player name
* Player symbol (X / O)

### Board

Handles:

* Board creation
* Board display
* Move placement
* Move validation

### Game

Handles:

* Game flow
* Turn management
* Win/draw logic
* Player switching

# ▶️ How to Run

## Clone the repository

```bash
git clone https://github.com/yourusername/tic-tac-toe-lld-python.git
```

## Navigate into the folder

```bash
cd tic-tac-toe-lld-python
```

## Run the game

```bash
python main.py
```
